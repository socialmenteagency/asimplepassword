# Security

Found a problem with A Simple Password? Report it privately through
[GitHub's private vulnerability reporting](https://github.com/socialmenteagency/asimplepassword/security/advisories/new),
not in a public issue.

In scope: the password generator (`site/gen.js`), the page at https://asimplepassword.com, and anything that
could expose a generated password. You'll get a reply within a few days.
